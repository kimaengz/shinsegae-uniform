# 견적 접수 연결하기 (구글 시트 · 드라이브 · 메일)

홈페이지 견적함에서 보낸 요청이 구글 시트에 한 줄씩 쌓이고, 첨부 파일은 드라이브에 저장되며, 담당자와 고객에게 메일이 갑니다. 비용은 들지 않습니다. 처음 한 번 15분 정도 걸립니다.

견적을 받을 **회사 구글 계정**으로 로그인한 상태에서 진행하세요.

## 1. 시트 만들기

1. [sheets.new](https://sheets.new)에서 새 시트를 만들고 이름을 `신세계유니폼 견적`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣습니다.
4. 맨 위 `STAFF_EMAIL`의 `[담당자 이메일]`을 실제 주소로 바꾸고 저장합니다.

## 2. 처음 한 번 실행

1. 위쪽 함수 선택 칸에서 `setup`을 고르고 **실행**을 누릅니다.
2. 권한 요청 창이 뜨면 회사 계정을 고르고 허용합니다. ("확인되지 않은 앱" 경고가 나오면 **고급 → 이동**)
3. 시트에 머리줄과 '상태' 드롭다운이 생기고, 드라이브에 `신세계유니폼 견적 첨부파일` 폴더가 생깁니다.

## 3. 웹 앱으로 배포

1. **배포 → 새 배포** → 유형 **웹 앱**.
2. 실행 사용자: **나**, 액세스 권한: **모든 사용자**.
3. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 4. 홈페이지에 연결

GitHub 저장소에서 `data/site.json`을 열고 `"quoteEndpoint": ""`의 따옴표 안에 위 URL을 붙여 넣은 뒤 저장(Commit)합니다. 1~2분 뒤 사이트에 반영됩니다.

## 5. 확인

홈페이지에서 시험 견적을 하나 보내고 시트에 한 줄이 생기는지, 담당자 메일이 오는지 확인합니다. 시험 줄은 지워도 됩니다.

## 알아 둘 것

- 개인 구글 계정은 하루 메일 100통까지 보낼 수 있습니다(담당자 1통 + 고객 1통 = 견적 1건당 2통).
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다. URL은 그대로입니다.
- 진행 상황은 시트의 '상태' 칸에서 접수 → 상담 중 → 샘플 발송 → 계약 / 보류로 바꿉니다.
