# 제품·이미지 수정 안내 (담당자용)

제품 정보와 이미지는 GitHub 웹에서 직접 고칩니다. 저장(Commit)하면 1~2분 뒤 홈페이지에 자동 반영됩니다. 프로그램 설치는 필요 없습니다.

## 어디를 고치나요

| 바꾸고 싶은 것 | 파일 |
| --- | --- |
| 제품 이름, 색상, 단가, 공개 여부, 자수 위치, 신제품 표시 | `data/products.csv` |
| 사이즈 실측표 | `data/sizes.csv` |
| 카테고리 이름·설명 | `data/categories.csv` |
| 납품 실적 기관 목록 | `data/references.csv` |
| 대표번호, 이메일, 주소, 단가 전체 공개 여부 | `data/site.json` |
| 제품 사진 | `public/images/products/<상품 코드>/` |

## 글자 고치기 (예: 단가 변경)

1. 저장소에서 `data/products.csv`를 열고 오른쪽 위 연필 아이콘(Edit)을 누릅니다.
2. 해당 줄의 값을 고칩니다. 쉼표(,)가 칸 구분이므로 쉼표를 지우거나 더하지 않게 주의하세요.
3. 아래 **Commit changes**를 누릅니다.

### products.csv 칸 설명

| 칸 | 쓰는 법 | 예 |
| --- | --- | --- |
| code | 영문 1자 + 숫자. 바꾸면 주소가 바뀝니다 | `A01` |
| category | categories.csv의 id | `scrubs` |
| colors | `이름:영문:색코드`를 `\|`로 이어 씀 | `와인:wine:#6E2236\|네이비:navy:#2F3B57` |
| sizes | `\|`로 이어 씀 | `S\|M\|L\|XL` |
| price_10 / price_50 / price_100 | 수량 구간별 1벌 단가, 숫자만 | `32000` |
| price_public | 단가 공개 `Y`, 비공개 `N` | `Y` |
| embroidery | 가능한 자수 위치: 왼가슴, 오른가슴, 소매, 등 | `왼가슴\|소매` |
| is_new | 신제품이면 `Y` | `N` |
| order | 목록에서 보이는 순서 (작을수록 앞) | `1` |

## 사진 올리기

제품마다 상품 코드 폴더를 씁니다. 예: `public/images/products/A01/`

| 사진 | 파일 이름 | 크기 |
| --- | --- | --- |
| 목록 썸네일 | `thumb.jpg` | 720×1080 (2:3) |
| 색상별 멀티뷰 | `<색상 영문>/front.jpg`, `back.jpg`, `neck.jpg`, `left.jpg`, `right.jpg` | 1200×1800 (2:3) |
| 상세페이지 이미지 | `detail-1.jpg`, `detail-2.jpg` … (번호 순서대로 위에서 아래) | 가로 720 |

색상 영문은 products.csv colors 칸의 가운데 값입니다. (`와인:wine:#6E2236`이면 `wine`)

1. 저장소에서 `public/images/products/`로 들어가 **Add file → Upload files**를 누릅니다.
2. 새 폴더가 필요하면 업로드 화면 위쪽 경로 칸에 `A01/wine/`처럼 적고 파일을 끌어다 놓습니다.
3. **Commit changes**를 누릅니다.

사진이 없는 자리는 옷 모양 자리표시로 보이므로, 사진을 나눠서 올려도 됩니다. jpg·png·webp 모두 됩니다.

## 저장했는데 반영이 안 될 때

저장소 위쪽 **Actions** 탭을 엽니다.

- 초록 체크: 반영 완료. 브라우저를 새로고침하세요.
- 빨간 X: 데이터 오류로 배포가 멈춘 것입니다. 실패한 항목을 열면 `products.csv 5번째 줄: 단가 공개(Y)인데 …`처럼 고칠 곳이 나옵니다. 그 줄을 고쳐 다시 저장하면 됩니다. 오류가 있는 동안에도 홈페이지는 이전 상태로 정상 운영됩니다.
