# 제품·이미지 수정 안내 (담당자용)

제품 정보와 이미지는 GitHub 웹에서 직접 고칩니다. 저장(Commit)하면 1~2분 뒤 홈페이지에 자동 반영됩니다. 프로그램 설치는 필요 없습니다.

## 어디를 고치나요

| 바꾸고 싶은 것 | 파일 |
| --- | --- |
| 제품 이름, 색상, 단가, 공개 여부, 자수 위치, 신제품 표시 | `data/products.csv` |
| 사이즈 실측표 (code 칸에 `A01`처럼 상품 코드를 쓰면 그 제품만, `scrubs`처럼 카테고리 id를 쓰면 그 카테고리 전체에 적용. 둘 다 있으면 상품 코드가 우선) | `data/sizes.csv` |
| 카테고리 이름·설명 | `data/categories.csv` |
| 제작사례 기관 목록 (유형, 기관명, 보조 설명: 지점·납품 품목 등, 순서) | `data/references.csv` |
| 대표번호, 이메일, 주소, 단가 전체 공개 여부, 자수 추가금(`embroideryPrice`: 로고·이름 1벌·위치 1곳당 원) | `data/site.json` |
| 제품 사진 | `public/images/products/<상품 코드>/` |

## 글자 고치기 (예: 단가 변경)

1. 저장소에서 `data/products.csv`를 열고 오른쪽 위 연필 아이콘(Edit)을 누릅니다.
2. 해당 줄의 값을 고칩니다. 쉼표(,)가 칸 구분이므로 쉼표를 지우거나 더하지 않게 주의하세요.
3. 아래 **Commit changes**를 누릅니다.

### products.csv 칸 설명

| 칸 | 쓰는 법 | 예 |
| --- | --- | --- |
| code | 영문 1자 + 숫자. 바꾸면 주소가 바뀝니다 | `A01` |
| category | categories.csv의 id | `scrubs` |
| colors | `이름:영문:색코드`를 `\|`로 이어 씀 | `와인:wine:#6E2236\|네이비:navy:#2F3B57` |
| sizes | `\|`로 이어 씀 | `S\|M\|L\|XL` |
| price_10 / price_50 / price_100 | 수량 구간별 1벌 단가, 숫자만 | `32000` |
| price_public | 단가 공개 `Y`, 비공개 `N` | `Y` |
| embroidery | 가능한 자수 위치: 왼가슴, 오른가슴, 소매, 등 | `왼가슴\|소매` |
| is_new | 신제품이면 `Y` | `N` |
| order | 목록에서 보이는 순서 (작을수록 앞) | `1` |
| badge | 카드 아래 회색 상자에 버건디 글씨로 보이는 문구. 비우면 신제품은 `NEW`, 나머지는 표시 없음 | `NEW 컬러` |

## 사진 올리기

제품마다 상품 코드 폴더를 씁니다. 예: `public/images/products/A01/`

| 사진 | 파일 이름 | 크기 |
| --- | --- | --- |
| 목록 썸네일 | `thumb.jpg` | 720×1080 (2:3) |
| 색상별 사진 (상세 왼쪽 5칸) | `<색상 영문>/1.png` ~ `5.png` (번호 = 위에서부터 순서) | 720×1080 (2:3) |
| 상세페이지 이미지 | `detail-1.jpg`, `detail-2.jpg` … (번호 순서대로 위에서 아래) | 가로 720 |

색상 영문은 products.csv colors 칸의 가운데 값입니다. (`와인:wine:#6E2236`이면 `wine`)

1. 저장소에서 `public/images/products/`로 들어가 **Add file → Upload files**를 누릅니다.
2. 새 폴더가 필요하면 업로드 화면 위쪽 경로 칸에 `A01/wine/`처럼 적고 파일을 끌어다 놓습니다.
3. **Commit changes**를 누릅니다.

사진이 없는 자리는 기본 사진(TEST)으로 보이므로, 사진을 나눠서 올려도 됩니다. jpg·png·webp 모두 됩니다.

## 제품 외 사진 (홈·신제품·회사소개)

`public/images/` 아래에 아래 이름으로 넣으면 기본 사진(TEST) 대신 보입니다. jpg·png·webp 모두 됩니다.

| 자리 | 파일 | 크기 |
| --- | --- | --- |
| 홈 맨 위 큰 사진 | `hero.jpg` | 세로형 약 1200×1440 (5:6), 배경은 아이보리 #F7F2EC |
| 신제품 페이지 맨 위 사진 | `new-hero.jpg` | 2880×1440 |
| 홈 '현장별 유니폼' 카테고리 6칸 | `categories/scrubs.jpg`, `clinic`, `office`, `gown`, `patient`, `knit` | 1200×900 (4:3) |
| 회사소개 브랜드 사진 | `about/brand.jpg` | 1200×900 (4:3) |
| 회사소개 공정 사진 (재단·봉제·자수·검수) | `about/process-1.jpg` ~ `process-4.jpg` | 1600×1067 (3:2) |
| 회사소개 인증서 (여성기업·직접생산확인·나라장터) | `about/cert-1.jpg` ~ `cert-3.jpg` | 1200×900 (4:3) |
| 카카오톡·문자로 링크 보낼 때 뜨는 미리보기 사진 | `og.jpg` | 1200×630 |

사진이 없는 자리에 보이는 기본 사진은 `placeholder.png` 한 장입니다. 이 파일을 같은 이름으로 바꾸면 모든 빈 자리가 함께 바뀝니다.

## 저장했는데 반영이 안 될 때

저장소 위쪽 **Actions** 탭을 엽니다.

- 초록 체크: 반영 완료. 브라우저를 새로고침하세요.
- 빨간 X: 데이터 오류로 배포가 멈춘 것입니다. 실패한 항목을 열면 `products.csv 5번째 줄: 단가 공개(Y)인데 …`처럼 고칠 곳이 나옵니다. 그 줄을 고쳐 다시 저장하면 됩니다. 오류가 있는 동안에도 홈페이지는 이전 상태로 정상 운영됩니다.

## AI 제품 사진 자동 반영

- GPT 결과 폴더(`~/chat gpt/신세계유니폼_AI_완성`)의 `작업목록.csv`에서 상태가 **완료**인 사진만 5분마다 사이트에 올라갑니다.
- 제품 코드(A01 등)의 **기본 색**(products.csv colors 맨 앞) 사진으로 들어가며, 그 색의 기존 사진은 교체됩니다.
- 순서: 정면 → 뒷면 → 옆면 → 디테일. 카드에서는 앞 5장, 상세 페이지에서는 전부 보입니다.
- 원본(2048px PNG, 장당 3~6MB)은 가운데 기준 2:3으로 잘라 960×1440 WebP(장당 20~90KB)로 줄여 올립니다.
- 바로 반영: `scripts/ai-sync.sh` 실행 · 기록: `~/Library/Logs/shinsegae-ai-sync.log`
- 자동 반영 끄기: `launchctl unload ~/Library/LaunchAgents/com.haremi.shinsegae-ai-sync.plist`
